# Проверка замечаний к FoldBOcean — 28.10.2026

Проверены исходники и работающая Windows-сборка. Изменения касаются сохранения, проверки конфигурации, открытия панели и диагностических тестов.

| Замечание | Результат |
|---|---|
| Разные валидаторы | Подтверждено. Общие лимиты вынесены в menu-limits.json. Добавлены проверки типов и длины пути, NUL, уникальности id между группами и программами, допустимых id и позиций. Исправлен старый лимит корневых групп. Общие тестовые JSON проходят JS, Rust и C++. |
| Изменения остаются после ошибки записи | Подтверждено. Введена очередь сохранений, подтверждённый снимок и откат интерфейса. Зависимые записи из ошибочного состояния отменяются. Следующее новое изменение можно сохранить. |
| Перенос группы переполняет кольцо потомков | Подтверждено. Проверка всего дерева выполняется до закрытия формы и записи. |
| Исключение из оконной процедуры | Подтверждено по коду. Добавлена граница исключений вокруг Win32 callback, обработка ошибок экспорта значков. Некорректный JSON/UTF-8 сохраняет прежнее рабочее состояние. |
| Повторное чтение битого JSON при каждом вызове | Исправлено. Обычное открытие использует конфигурацию в памяти; изменения отслеживает файловый watcher. Одинаковое сообщение об ошибке не повторяется на каждом вызове. |
| Синхронные значки при каждом открытии | Подтверждено. Нативная панель извлекает значки асинхронно, через ограниченный по времени дочерний процесс. Быстрые повторные открытия используют кэш; после 30 с в трее он освобождается. |
| defaults повторно парсит ресурсы | Исправлено: встроенные пресеты разбираются один раз. |
| Общий .tmp, отсутствие backup/fsync | Подтверждено. Уникальные временные файлы, sync_all, атомарная замена с write-through, межпроцессная блокировка и предыдущая корректная версия в .bak. |
| Подстроки в параметрах CLI | Подтверждено. CommandLineToArgvW, точные имена опций и число аргументов. Неизвестная команда возвращает код 2. |
| CARGO_MANIFEST_DIR в пути релиза | Исправлено: поиск в каталоге исходников оставлен только debug-сборке. Release ищет панель рядом с EXE настроек. |
| id вставляется в HTML без экранирования | Подтверждено. Атрибуты экранируются, входные id дополнительно проверяются. |
| Подсказки привязаны к прямоугольникам подписи | Исправлено. Нативные подсказки используют тот же hit-test анимированного сектора или блока, что и выбор элемента. |
| Нет npm test и запуска smoke-тестов | Исправлено. Добавлены команды и управляющий скрипт, самостоятельно поднимающий Vite. Старые тесты обновлены под нынешние режимы, полные названия и анимации; устаревшие ожидания удалённых кнопок убраны. |
| Личные абсолютные пути в PERFORMANCE.md | Исправлено. Относительные ссылки и исходные обезличенные измерения включены в docs/performance. Это исторические измерения, не новые показатели исправленной сборки. |
| Без profile.release настройки не оптимизируются | Неверно. Cargo release уже оптимизирован; реальная сборка завершилась с profile [optimized]. LTO/strip — дополнительные настройки, а panic=abort не является универсальной оптимизацией надёжности. |
| Нет рабочей папки при запуске | Частично неверно: для EXE уже используется его родительская папка. Отдельных пользовательских полей аргументов и рабочей папки действительно нет. Для параметров можно добавить .lnk. |
| Глобальное поглощение СКМ | Существующее поведение назначенного бинда, не случайная регрессия. Короткий клик с пропуском в другие приложения и исключения по приложениям — отдельные функции. Ограничения документированы. |
| Старые имена SpiderWeb | AppData и IPC оставлены ради совместимости. Переименование этих идентификаторов без миграции потеряло бы доступ к прежним данным или создало второй экземпляр панели. |
| Плотные заголовки и один translation unit | Замечание по сопровождению обоснованно. Новая логика разделена на небольшие модули; полной переработки старого рендерера в этом исправлении нет. |

При прогоне интерфейса также исправлено поведение множественного выделения: обычная рамка заменяет выбор, Ctrl/Shift добавляет к нему; одиночный клик сокращает выбор после отпускания, не мешая переносить несколько блоков; Escape снимает выбор. Восстановлено отображение локальных осей выбранной ветви.

Проверки выполняются на отдельных тестовых файлах. Проверка живых биндов сохраняет и восстанавливает пользовательский конфиг. Установщик не создавался.

Проверено после исправлений: 37 нативных тестов, 18 тестов Rust, 26 тестов JS и все 21 браузерный smoke-сценарий. Обе release-сборки успешно собраны, совместимые копии EXE синхронизированы. На живой панели отдельно проверены клавиатурные hold/toggle, удержание СКМ и изменение бинда без перезапуска. Проверку настоящего ввода следует запускать отдельно от браузерной автоматизации: они конкурируют за фокус рабочего стола.
