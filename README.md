# FoldBOcean

Настраиваемая панель быстрого запуска приложений для Windows. Собери программы в группы и вызывай их сочетанием **Alt + `**. Можно выбрать круговое меню с вложенными кольцами или паутину со свободным расположением блоков.

Фоновая панель написана на C++ и работает из трея. Окно настроек — отдельное приложение на Tauri 2: его можно полностью закрыть, оставив только панель.

## Возможности

- Два режима: **круг** и **паутина**, с общими группами и приложениями.
- Вложенные группы, раскрытие наведением и плавные анимации появления и сворачивания.
- Редактор расположения: перетаскивание, множественное выделение, привязка по координатам и пресеты размещения.
- Цвета, прозрачность, размытие, скругления, размеры и RGB-переливание элементов.
- Сохранение собственных пресетов всей конфигурации, поиск, применение и переименование. Искусственного ограничения на количество нет.
- Настраиваемый бинд клавиатуры или мыши, режим удержания или переключения, выбор монитора и автозапуск с Windows.
- Автоматическая блокировка вызова поверх полноэкранных программ на выбранном мониторе. Прозрачные оверлеи, пропускающие клики, не мешают работе панели.
- Системная группа с инструментами Windows; собственные приложения и ярлыки `.lnk`.
- Значки и полные названия из EXE, индивидуальный режим **«Без значка — больше текста»** и сообщение о потерянном файле программы.

## Скачать

Готовые файлы находятся в [Releases](https://github.com/Nextems/FoldBOcean/releases/latest).

- **FoldBOcean-0.1.0-Setup-x64.exe** — установщик для текущего пользователя, с ярлыками и удалением через Windows.
- **FoldBOcean-0.1.0-Portable-x64.zip** — версия без установщика. Распакуй и держи оба EXE в одной папке.
- **SHA256SUMS.txt** — контрольные суммы файлов релиза.

Версия без установщика также хранит настройки в AppData, а не рядом с EXE. Установщик пока не подписан цифровым сертификатом издателя.

## Требования

- Windows 10/11 x64.
- Microsoft Edge WebView2 Runtime для окна настроек. Если его нет, установщик скачает и установит компонент; для этого потребуется интернет.

Сама панель не использует WebView и не требует запущенного окна настроек или локального сервера.

## Использование

1. Установи приложение либо распакуй архив и запусти `FoldBOcean.exe`.
2. Открой **«Настройки…»** через значок в системном трее. В архиве окно настроек также запускается файлом `FoldBOcean Settings.exe`.
3. Создай группы и добавь приложения. Переключайся между **«Круг»** и **«Паутина»**, чтобы настроить внешний вид и расположение.
4. Удерживай **Alt + `** — клавишу **Ё под Esc**. Отпусти её над приложением, чтобы запустить его.

Сочетание привязано к клавише и работает в русской и английской раскладках. В **«Вызов панели → Взаимодействие»** можно выбрать другой бинд, переключиться на режим нажатия, изменить задержки и монитор. В режиме нажатия приложение запускается щелчком.

**Esc** закрывает панель, **ПКМ / Backspace** возвращает предыдущий слой. Для полного завершения выбери **«Выход»** или **«Завершить всё»** в трее. Закрытие окна настроек освобождает его процесс и оставляет панель работающей.

## Настройка меню

В кольцах элементы делят окружность поровну; пустые позиции не отображаются. Вместимость уровней — **5 / 7 / 13**, затем сохраняется предел 13. Новые кольца добавляются к предыдущим; на глубоких уровнях старые плавно скрываются, освобождая место.

В паутине можно перемещать группы, приложения и точки ветвей. **Ctrl / Shift** добавляет блоки к выделению, рамка выделяет несколько элементов, **Del** удаляет выбранное с подтверждением. **ПКМ** в редакторе открывает добавление группы или программы.

Системная группа защищена от удаления, а пути системных команд — от изменения. Имена, порядок, оформление и положение её элементов можно настраивать. Внутрь системной группы можно добавить одну собственную подгруппу.

Полные названия сохраняются до 256 символов. Обычные подписи сокращаются многоточием: в круге до **8 / 12 / 10** символов по уровням, в паутине — до **12**. Галочка **«Без значка — больше текста»** даёт до **20** символов в круге и **15** в паутине, с переносами. Если программа не найдена, сообщение содержит её полное название без сокращения.

Для запуска с аргументами создай Windows-ярлык `.lnk` с нужными параметрами и добавь его в меню.

## Пресеты и данные

Вкладка **«Пресеты»** сохраняет группы, приложения, расположение обоих режимов, оформление и параметры вызова. Можно хранить сотни пресетов, искать их по имени, обновлять текущей конфигурацией и применять с подтверждением.

Данные находятся в каталоге:

```text
%APPDATA%\com.spiderweb.settings\
├── config.json       — текущая конфигурация
├── config.json.bak   — предыдущая корректная версия
└── presets\          — пользовательские пресеты в отдельных JSON
```

Имя каталога сохранено от раннего названия SpiderWeb для совместимости. Для резервной копии сохрани эту папку. При переносе на другой компьютер проверь пути к программам. По умолчанию удаление приложения сохраняет пользовательские данные.

## Запуск из исходников

Нужны Node.js 22.12+, Rust stable и Visual Studio Build Tools с компонентами **Desktop development with C++** и Windows SDK.

```powershell
git clone https://github.com/Nextems/FoldBOcean.git
cd FoldBOcean
npm ci
powershell -NoProfile -ExecutionPolicy Bypass -File native/build.ps1 -NativeOnly
npm run tauri dev
```

Сборка установщика:

```powershell
npm run build:installer
```

Результат появится в `release/`. Параметры установщика находятся в `src-tauri/tauri.installer.conf.json`.

Проверки:

```powershell
npm test
cargo test --manifest-path src-tauri/Cargo.toml
powershell -NoProfile -ExecutionPolicy Bypass -File native/build.ps1 -NativeOnly -Test
Copy-Item release/FoldBOcean.exe release/SpiderWeb.exe -Force
npm run test:smoke
```

Перед нативной сборкой заверши работающую панель. Браузерные проверки используют Microsoft Edge; скрипт самостоятельно запускает Vite. Подробности реализации и дополнительные проверки — в [документации разработки](docs/DEVELOPMENT.md). [Исторические замеры ресурсов](PERFORMANCE.md) относятся к указанной в отчёте сборке и не являются замерами каждого последующего релиза.

Стек: **C++17 · Win32 · GDI+ · Tauri 2 · Rust · JavaScript · Vite**.
