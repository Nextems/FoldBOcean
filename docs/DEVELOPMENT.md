# FoldBOcean

FoldBOcean — нативная круговая панель C++ / Win32 / GDI+ и отдельные настройки на Tauri 2. В фоновом лаунчере нет WebView и сервера.

## Запуск

Готовые файлы: release/FoldBOcean.exe и release/FoldBOcean Settings.exe. Держите их рядом. Первый запускает значок в трее, второй — окно настроек.

По умолчанию панель вызывается удержанием Alt + ` (клавиша Ё / тильда под Esc, код VK_OEM_3). Сочетание привязано к клавише и работает независимо от раскладки. Режим нажатия, другой бинд, монитор и задержки задаются в «Круговая панель → Взаимодействие». Esc закрывает панель; ПКМ / Backspace возвращает предыдущий слой. В режиме удержания отпускание бинда над приложением запускает его. В режиме нажатия — клик. Клавиши 1–7 выбирают элемент последнего кольца.

## Автозапуск

В «Вызов панели → Взаимодействие» доступен переключатель «Запускать вместе с Windows». Он включает запуск фонового FoldBOcean.exe с параметром --background при входе текущего пользователя в Windows; окно настроек не открывается. Администраторские права не нужны. Настройка читается из HKCU\Software\Microsoft\Windows\CurrentVersion\Run, значение FoldBOcean; выключение удаляет только это значение. Если переместить папку программы, включите переключатель снова из нового расположения.

## Два вида меню

В настройках над предпросмотром есть кнопки «Круг / Паутина». Выбор сохраняется в launcher.view (radial / web) и применяется к следующему вызову лаунчера. Группы, программы и команды общие. Геометрия паутины остаётся в layout и не изменяется при работе в круговом режиме.

В режиме «Паутина» справа в разделе «Элемент → Вид паутины» доступны выбор цвета, ползунок оттенка, прозрачность 0–100% и размытие 0–24 px. Они меняют фон всех блоков, сохраняя чёткие подписи и значки. Настройки хранятся отдельно в webStyle и не меняют оформление кругового меню. В лаунчере размытие использует снимок рабочего стола при открытии; снимок освобождается при закрытии меню.

В обоих редакторах есть разделы «Размер меню» и «RGB · переливание цветов». RGB включается отдельно для секторов круга, блоков и веточек паутины; общая скорость — 0.2–3×. Цвета элементов сдвинуты по фазе, статические цвета сохраняются. В предпросмотре анимируются только свойства отрисовки; в лаунчере таймер работает только при открытом меню и включённом RGB.

Длительность открытия меню и новых слоёв задаётся ползунком «Анимация раскрытия»: 100–1500 мс, по умолчанию 450 мс. Настройка общая для круга и паутины, сохраняется в appearance.openMs. Кнопка «Проверить анимацию» повторяет раскрытие в предпросмотре. Погружение колец, их возврат и затухание ветвей сохраняют отдельные длительности. Раскрытие использует плавное ускорение и замедление. Блоки паутины проявляются с небольшим движением наружу; круг и каждое новое кольцо появляются с лёгким увеличением до полного размера. Открытые кольца не повторяют анимацию при добавлении следующего, смене цвета или загрузке значков. В лаунчере отсчёт анимации нового кольца начинается после загрузки иконок. Начиная с пятого кольца старые слои погружаются в основное за 400 мс: при пяти кольцах скрывается второе, при шести — также третье и далее; основное кольцо остаётся видимым. При возврате соответствующий слой возвращается за 350 мс. Быстрое изменение направления продолжает движение с текущей прозрачности и масштаба. Погружённые слои не принимают клики. Оставшиеся внешние кольца плавно сдвигаются на освободившиеся места, сохраняя толщину и промежуток 10 px; при возврате скрытого кольца они расходятся обратно. Видимый внешний радиус ограничен четырьмя кольцами: основным и тремя последними. Ветви паутины при закрытии тускнеют и немного стягиваются к своей группе за 450 мс, оставаясь в кадре до завершения; возврат курсора разворачивает исчезновение. Без RGB кадровый таймер останавливается после завершения переходов; закрытое меню не анимируется.

Масштаб паутины и круга задаётся независимо в пределах 50–180%; при нехватке места лаунчер вписывает меню в монитор. Уменьшение X задаётся в процентах от основного размера: 100%, 100% − X, 100% − 2X, затем величина сохраняется. По умолчанию X = 6%, диапазон 0–12%. Размеры слоёв считаются линейно; координаты и порядок элементов не изменяются. Подписи паутины используют Segoe UI Variable Text с обычным начертанием.

ПКМ в редакторе паутины открывает контекстное меню. На группе можно добавить подгруппу или программу прямо в неё, на приложении — в его родительскую группу, на свободном месте — основную группу либо программу с выбором группы. Для sys prog приложения направляются в единственную свою подгруппу; ограничения вместимости и системных команд сохраняются. Меню закрывается по Esc, клику снаружи или смене вида.

В паутине доступны свободное перемещение блоков и узлов, Ctrl/Shift-выделение, рамка, привязка, выравнивание, пресеты, длина ветвей, масштаб и перемещение холста с Alt. В нативном режиме ветви раскрываются по наведению с плавной анимацией и зоной удержания. Между группами идут прямые связи; приложения соединяются с узлом группы. Основные папки не имеют общего центрального узла: одна папка не рисует лишних связей, две соединяются напрямую, три и более по умолчанию связаны друг с другом. В разделе «Связи основных папок» можно редактировать концы линий, добавлять и удалять связи, выбирать «Все со всеми» или «Цепочка». Настройка хранится в layout.rootLinks; удаление связующего ребра, изолирующее папку, предотвращается. При удалении промежуточной папки или добавлении новой связность восстанавливается автоматически. Поддерживаются текущие вложенные группы и до 13 элементов ветви.

## Кольца

Центр пустой и прозрачен. Первое кольцо содержит только существующие корневые группы. Два сектора занимают по 50%, три — по трети; пустых позиций нет. При наведении на группу снаружи добавляется её кольцо, старые остаются видимыми и доступными. Секторы каждого нового кольца снова делят полный круг поровну.

Толщина первого кольца — 60 условных пикселей, следующего — 56.4, третьего — 52.8; далее уменьшение прекращается. Размер значков: 28 / 24 / 20 px для первого, второго и третьего кольца. Начиная с третьего значки остаются 20 px. Уменьшение значков независимо от толщины кольца и шрифта; они смещены наружу от подписи, чтобы оставить читаемый зазор. Общий масштаб и линейное уменьшение X настраиваются в разделе «Размер меню». На длинных цепочках используется общий масштаб, чтобы кольца помещались на выбранном экране. В первом кольце до 5 элементов, во втором до 7, в третьем и следующих до 13; глубина пользовательских групп не ограничена, циклическая вложенность запрещена.

Материал секторов — тёмное стекло с небольшой цветной тонировкой. Лаунчер при вызове захватывает фон в память и размывает его уменьшением с плавной интерполяцией. Этот фон используется только внутри секторов, освобождается при закрытии и не записывается на диск; нет постоянного захвата экрана. Значки и текст рисуются поверх размытия. Значки повёрнуты по той же касательной, что и подписи; их прямоугольник вписан в сектор, отступает от внешней дуги и дополнительно обрезается формой сектора. Окно включено в захват экрана и запись (WDA_NONE).

Панель открывается по центру рабочего пространства основного монитора. Можно выбрать другой; отключённый монитор заменяется основным.

## Настройки

В обоих редакторах выберите элемент и нажмите Del: появится подтверждение удаления из меню. В паутине можно удалить несколько выбранных элементов одной операцией. Для группы учитываются все вложенные группы и приложения; диалог показывает их количество. Отмена и Esc сохраняют данные. Системные элементы защищены; Del в полях ввода не запускает удаление из меню.

Вкладка «Все группы» создаёт группы, вложенные группы и приложения. Системная группа сохраняет защищённые команды Windows; их имена и порядок можно менять, пути и удаление защищены. В ней остаётся одна своя подгруппа, внутри которой доступны дальнейшие уровни. Полные имена хранятся до 256 символов; подпись первого кольца показывает до 8, второго — до 12, третьего и следующих — до 10 символов. В паутине подпись ограничена 12 символами. Длинные подписи заканчиваются тремя точками внутри лимита: при 12 символах это первые 9 + "...", при 8 — первые 5, при 10 — первые 7. Подписи не переносятся на вторую строку. Полное имя видно в настройках и подсказке. При выборе EXE имя берётся из FileDescription или ProductName в ресурсах версии файла, при отсутствии этих полей — из имени файла; для ярлыков читается целевой EXE. Путь запуска остаётся исходным. Кнопка «Название из EXE» позволяет обновить имя, а ручной ввод сохраняется как пользовательское название. Старые приложения без отметки источника имени обновляются один раз при открытии настроек.

Вкладка «Круговая панель» показывает реальные кольца. При возврате курсора с дочерней папки на родительскую лишние дочерние слои закрываются через closeDelayMs; возврат к дочернему слою до истечения задержки отменяет закрытие. Переход через зазор сам по себе не закрывает слой. Наведение или выбор группы раскрывает её слой. Перетаскивание сектора меняет порядок внутри кольца, кнопки «Раньше / Позже» делают то же. Подписи увеличены и рисуются по дуге, с правильным направлением чтения в нижней половине. Ползунок поворачивает выбранное кольцо. «Общий цвет» перекрашивает все сектора; выбранному сектору можно задать собственный цвет или вернуть общий.

В центре редактора находится «Добавить»: выбор группы или программы открывает соответствующую форму для текущего кольца. В разделе «Оформление» доступны переключатель скругления, радиус 0–18 px и степень размытия 0–24. В нативном режиме центр остаётся пустым.

Исходная вместимость рассчитана по длине дуги подписи: floor(2π × (внутренний радиус + 12) / (лимит символов × размер шрифта × 0.6 + 12)). Шрифты: 16 / 15 / 14.5 px. Получается 5 / 7 / 13 элементов; далее сохраняется лимит 13. Для широких букв подпись дополнительно вписывается в доступную дугу.

Значки извлекаются из доступного крупного ресурса EXE или системного списка Windows, обрабатываются с корректным premultiplied alpha и сохраняются в кеше 48×48. Уменьшение до размера сектора выполняется с качественной интерполяцией. Старый путь Bitmap(HICON), теряющий альфа-канал некоторых значков, не используется.

Настройки сохраняются автоматически. Существующие группы и команды SpiderWeb используются без потери; радиальная геометрия хранится отдельно в radial.color, radial.colors и radial.rotation. Путь JSON оставлен совместимым: %APPDATA%/com.spiderweb.settings/config.json. Старые координаты паутины не используются.

## Проверка конфигурации и восстановление

Вместимость 5 / 7 / 13, максимальная длина имени, id и пути заданы в `src/menu-limits.json`. JS, Rust и C++ читают один контракт; общие примеры корректных и ошибочных конфигураций находятся в `tests/config-cases.json`. При изменении шрифтов вместимость меняется явно в этом файле после проверки геометрии.

Сохранение сериализуется. При ошибке интерфейс возвращается к последней подтверждённой конфигурации; зависимые от отклонённого изменения записи отменяются. Перед переносом группы проверяется вместимость всех её потомков.

Рядом с `%APPDATA%/com.spiderweb.settings/config.json` хранится `config.json.bak` — предыдущая корректная версия. Запись использует уникальный временный файл, сброс данных на диск, атомарную замену и межпроцессную блокировку. Повреждённый основной файл не затирается автоматически. Для восстановления завершите панель и настройки, сохраните повреждённый JSON под другим именем и скопируйте `config.json.bak` в `config.json`, если копия существует. При первом сохранении резервной копии ещё нет. Пустой `config.json.lock` — служебный файл; он сам по себе не означает занятую блокировку.

В нативной панели значки загружаются вне UI-потока отдельным ограниченным по времени процессом (до 2,5 с на значок). Панель открывается сразу, значки появляются по готовности. Кэш сохраняется между быстрыми открытиями и освобождается после 30 с простоя; при изменении пути старый значок не используется. Изменения содержимого EXE по прежнему пути перепроверяются при следующем показе после 60 с.

Назначенная кнопка мыши используется панелью целиком, включая короткое нажатие. Для сохранения обычного поведения СКМ выберите клавиатурный бинд либо боковую кнопку. Доставка ввода над повышенными приложениями и защищённым рабочим столом ограничивается Windows; повышение прав панели автоматически не выполняется.

Поле приложения содержит путь к EXE, ярлыку `.lnk` или системной команде. Аргументы командной строки в него дописывать нельзя. Для запуска с аргументами добавьте Windows-ярлык с нужными параметрами. При прямом запуске EXE рабочая папка устанавливается в папку EXE.

Внутренние идентификаторы SpiderWeb, каталог AppData, mutex и события сохранены для совместимости с существующими настройками и работающими версиями. Пользовательское имя — FoldBOcean.

### Автоматические проверки

- `npm test` — проверки JSON и отката сохранения, без сервера и браузера.
- `cargo test --manifest-path src-tauri/Cargo.toml` — Rust: валидация, резервная копия, конкурентная запись.
- `powershell -NoProfile -ExecutionPolicy Bypass -File native/build.ps1 -NativeOnly -Test` — C++ и генерация актуальных JSON геометрии. Сначала завершите запущенную панель.
- `npm run test:smoke` — все браузерные smoke-тесты. Сам запускает и завершает Vite на 127.0.0.1:1420; отдельный dev-сервер не нужен. Нужны Microsoft Edge, зависимости npm и результаты предыдущей нативной сборки с `-Test`. Некоторые старые скрипты используют имя `release/SpiderWeb.exe`; перед тестами скопируйте туда свежий `release/FoldBOcean.exe`.
- `npm run test:smoke -- integrity-smoke.mjs` — только перенос переполненной группы и реальный отказ записи в интерфейсе.
- `pwsh -NoProfile -File scripts/native-hooks-smoke.ps1` — ввод в работающей панели; временно меняет конфиг и восстанавливает его в `finally`.

Индивидуальные `scripts/*-smoke.mjs` также можно запускать при работающем `npm run dev`. Полный список берёт `scripts/run-smoke.mjs` из каталога автоматически. Отчёт `PERFORMANCE.md` относится к указанной в нём сборке до последующих исправлений; сохранённые обезличенные измерения находятся в `docs/performance/2026-10-28/`.

## Полноэкранные приложения

FoldBOcean автоматически пропускает бинд и не раскрывает панель, когда на выбранном для неё мониторе активна полноэкранная программа. Проверяется фактическое окно на этом экране, в том числе когда фокус находится на другом мониторе. Полноэкранная программа на другом экране не блокирует панель. Обычное развёрнутое окно не считается полноэкранным. Когда полноэкранный режим закрыт или свёрнут, следующий вызов снова работает. Проверка выполняется при вызове, без фонового опроса.

## Пользовательские пресеты

Вкладка «Пресеты» позволяет сохранять всю конфигурацию под именем: группы и приложения, расположение обоих режимов, оформление, размеры, анимации, бинд и выбранный монитор. Доступны поиск, применение с подтверждением, обновление текущей конфигурацией, переименование и удаление. Применение меняет текущую конфигурацию; остальные сохранённые пресеты сохраняются.

Каждый пресет — отдельный JSON в `%APPDATA%\com.spiderweb.settings\presets`. Название хранится внутри файла, имя файла — безопасный уникальный id. Искусственного ограничения на количество нет: проверено сохранение 205 пресетов, повторное чтение и поиск. Фактическая вместимость зависит от свободного места на диске. Пресеты читаются окном настроек по запросу; нативная панель их в память не загружает. При обновлении сохраняется предыдущая версия файла `.json.bak`. Для резервного копирования достаточно скопировать каталог `presets`.

Браузерный предпросмотр использует localStorage, ограниченный квотой браузера. Повреждённый пресет показывается с ошибкой и не мешает работать с остальными. Для полного переноса на другой компьютер потребуется исправить пути к приложениям, если они отличаются.

## Подписи блоков и недоступные программы

В форме редактирования группы или программы и в инспекторе выбранного блока доступна галочка «Без значка — больше текста». Она убирает значок и даёт до 15 символов в паутине и до 20 в круге, включая многоточие при сокращении. Длинные подписи переносятся; в круге строки идут по дуге. Настройка индивидуальна для каждого блока, действует также на системные элементы и сохраняется в пресетах.

Если файл программы или цель ярлыка `.lnk` не найдены, вместо значка и короткой подписи показывается «Программа «полное название» не найдена :(». Для этого сообщения ограничения 15/20 не применяются: имя не сокращается, текст переносится и подгоняется по размеру блока. Само сохранённое название и путь не меняются. Обычные команды Windows и зарегистрированные URI не считаются отсутствующими файлами.

Проверка выполняется вне UI-потока, с тем же ограничением времени, что и загрузка значков. При повторном открытии проверяется актуальность пути; постоянный фоновый опрос не добавлен. После восстановления файла блок возвращается к обычному виду, а запуск снова работает. Ошибки прав доступа не выдаются за подтверждённое отсутствие файла.

Исправление блокировки оверлеями: полноэкранная проверка игнорирует окна с `WS_EX_TRANSPARENT`, которые пропускают клики, в том числе прозрачный OCR overlay на нескольких экранах. Такие окна не считаются активной полноэкранной программой. Регрессия проверяется тестовым прозрачным окном и `pwsh -NoProfile -File scripts/native-restart-smoke.ps1` — три полных перезапуска с проверкой текущего клавиатурного бинда в режиме удержания. Скрипт не меняет конфигурацию.

Подписи без значков используют Segoe UI Semibold в нативной панели и вес 600 Segoe UI в редакторе. Измерение текста для переносов выполняется тем же шрифтом, которым он отображается; при отсутствии Semibold в Windows нативная панель использует Segoe UI Bold.

## Сборка установщика Windows

Команда `npm run build:installer` собирает нативную панель, окно настроек и NSIS-установщик x64. Нужны Node.js/npm, Rust, Visual Studio C++ Build Tools и средства упаковки Tauri. Перед сборкой работающие экземпляры завершаются; панель, запущенная до сборки, затем возвращается в трей.

Результат: `release/FoldBOcean-0.1.0-Setup-x64.exe` и соседний файл `.sha256`. Версия берётся из `src-tauri/tauri.conf.json`. Отдельные параметры упаковки находятся в `src-tauri/tauri.installer.conf.json`, действия установки/удаления — в `src-tauri/installer-hooks.nsh`.

Установка выполняется для текущего пользователя. В комплект входят панель и настройки; в меню «Пуск» создаются ярлыки настроек и панели. При отсутствии WebView2 установщик скачивает и устанавливает его: на таком компьютере требуется интернет. Настройки и пресеты по умолчанию сохраняются при удалении. Если автозапуск уже был включён, его путь обновляется на установленную копию; при удалении удаляется только запись, указывающая на эту установленную папку.

Установщик пока не подписан цифровым сертификатом издателя.
